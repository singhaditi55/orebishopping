✨ CSS Animation Theory
CSS offers two core methods:

Transitions
Great for simple, one-step property changes (e.g., hover effects).

Involves properties like transition, duration, timing-function, and delay.

Example: Smooth shadow or color changes.

@keyframes Animations
Best for multi-step or looping effects.

Defines start-to-end stages using @keyframes.

Works with properties like animation-name, duration, iteration-count, etc.

🚀 Tailwind CSS Animation Utilities
Tailwind CSS makes animations easier with utility classes:

transition, duration-{x}, ease-{type}, delay-{x} for transitions.

transform, scale-{x}, rotate-{x}, translate-x/y-{x} for dynamic motion.

Predefined animation classes: animate-spin, animate-ping, animate-bounce, and more.

✅ Best Practices
Performance: Animate transform and opacity for optimal GPU rendering.

UX: Keep durations under 500ms and use animations purposefully.

Accessibility: Respect user preferences like reduced motion settings.

Mobile-first: Ensure smooth animations on all devices.
